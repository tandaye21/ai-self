# 演示截图说明

请将以下截图放入本目录（`docs/`），文件名需与下表一致，README 的「演示 Demo」板块会自动显示：

| 文件名 | 截图内容 | 怎么截 |
|--------|---------|--------|
| `demo-chat.png` | 流式对话界面 | 启动后发一条消息，截浏览器对话窗口 |
| `demo-memory.png` | 跨会话记忆召回 | 问它"还记得我之前说过的…吗"，截它的回复（体现记忆检索） |
| `demo-pet.png` | 桌面小宠 | 运行 `pet.bat`，截桌面悬浮小宠窗口 |

## 截图工具

- Windows 自带：`Win + Shift + S` 区域截图
- 录屏（可选，做 GIF 更生动）：`Win + G` 或 OBS
